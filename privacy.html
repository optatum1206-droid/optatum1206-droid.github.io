개인정보처리방침

시행일 2026-10-16

피부사전 업로더(이하 「도구」)는 유튜브 채널 피부사전의 운영자 한 사람이 자기 채널을 관리하려고 쓰는 내부 도구입니다. 이 방침은 도구가 YouTube API 서비스를 통해 다루는 정보를 설명합니다.

1. 접근하는 정보

  • 운영자 본인 채널의 기본 정보(채널 이름·ID·구독자 수), 영상 목록과 메타데이터(제목·설명·태그·공개 상태).
  • 운영자 본인 채널의 분석 수치(조회수·시청 시간·좋아요 수 등 YouTube Analytics 집계값).
  • 운영자가 업로드하려고 고른 영상 파일.

다른 사용자의 개인정보, 시청자 개인 식별 정보, 댓글 작성자 정보는 수집하지 않습니다.

2. 이용 목적

영상 업로드·예약·수정과 채널 성과 확인에만 씁니다. 광고, 판매, 프로파일링에는 쓰지 않습니다.

3. 보관과 저장

Google 인증 토큰과 가져온 정보는 운영자의 개인 컴퓨터에만 저장되며, 외부 서버로 보내거나 제3자와 공유하지 않습니다. 분석 수치는 운영자의 판단에 필요한 기간만 보관하고, YouTube API 서비스 정책이 정한 기간(최대 30일)이 지난 데이터는 다시 받아 갱신하거나 지웁니다.

4. 제3자 제공

어떤 정보도 판매하거나 제3자에게 제공하지 않습니다.

5. 접근 권한 철회

언제든지 Google 계정의 서드파티 액세스 설정에서 이 도구의 권한을 해제할 수 있습니다. 해제하면 컴퓨터에 저장된 토큰도 지웁니다.

6. 관련 정책

이 도구는 YouTube API 서비스를 사용합니다. YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.
